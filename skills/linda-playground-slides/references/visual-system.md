# 视觉系统与限定配色

## 固定色库

从 EXAT 主样式的 `:root` 提取以下 12 色；排除 WordPress 通用配色预设。机器可读配置见 `assets/palette.json`。

| Token | 色值 | 倾向 |
| --- | --- | --- |
| blue-03 | #0000CB | 深蓝 |
| blue-02 | #2546FF | 亮蓝 |
| blue-01 | #5C92FF | 浅蓝 |
| blue-00 | #BEEEFF | 冰蓝 |
| yellow-01 | #FFCE2E | 亮黄 |
| yellow-02 | #FFAE00 | 金黄 |
| orange-01 | #FF6200 | 橙 |
| red-01 | #FF0B00 | 红 |
| pink | #FF98FB | 粉 |
| green | #1C7511 | 绿 |
| black | #1C1D1E | 墨黑 |
| white | #EEEFEB | 暖白 |

这是界面色库。用户提供的照片、标识、二维码等内容资源保留其真实性，不做破坏性强制换色。

颜色过渡可以经过所选端点的插值；静止状态必须回到允许的 token。文字的抗锯齿像素不算新色。避免额外渐变停点、半透明遮罩叠出新的长期主色；优先使用实色面板、线条、裁切和几何结构。

## 给用户选择的方式

用户已选颜色时直接沿用；没有偏好时默认多彩。选项可以简短给出，不必阻塞制作：

| 组合 | 色彩范围 | 适合 |
| --- | --- | --- |
| 中性 + 橙 | black / white / orange-01 | 内容密集，强调关键动作 |
| 蓝 × 黄 | blue-02 / yellow-01 + 中性色 | 高能量标题与教学 |
| 粉 × 深蓝 | pink / blue-03 + 中性色 | 字体实验、柔和与锐利的对照 |
| 红 × 冰蓝 | red-01 / blue-00 + 中性色 | 对比、转折、简洁叙事 |
| 多彩编辑 | 蓝、黄、粉、绿、橙 + 中性色 | 长篇教程、多类别内容 |
| 全色库 | 12 色按场景分配 | 实验性展览、丰富叙事 |

“允许全色库”意味着有节奏地调用颜色。每个场景仍应有一个主色关系，避免所有颜色同时争夺注意力。不要默认在成品里增加调色器；只有用户需要现场选色时才提供。

## 交互状态与相邻颜色

1. 先建立模块邻接关系，包括桌面三列、平板两列、手机单列。
2. 为每个模块分配 default / hover / focus / active / expanded 背景 token。
3. 比较每对邻居的状态组合：默认对默认、交互对默认、默认对交互；多点触控或持久选中时也检查交互对交互。
4. 避免相同色；优先安排明显冷暖或明暗变化。蓝与相邻蓝、黄与相邻橙可以是有意的色阶，但不能让独立模块失去边界。
5. 双色方案可让 hover 改字体、下划线、轮廓或几何位置，保持底色；无需强迫每个 hover 换背景。
6. 在底色变化时同步更新文字、边框、焦点色。给正文达到至少 4.5:1 的对比；大字至少 3:1；交互轮廓也需清楚可见。

附带模板使用六组互不重叠的底色对，保证任意两个模板模块在切换后不会同色。实际生成新网格时重新判断其邻接关系，不能假设模板的分配永远合适。可用 `audit.py --palette` 检查声明色值，但相邻布局须在浏览器检查。

## 排版与字体

- 让文字承担视觉主体：超大标题、紧凑堆叠、长短行、字重跨度、字宽变化、数字与文字尺度反差。
- 配合章节号、细线、网格、圆、矩形和十字标记，建立编辑感。避免无意义的仪表盘卡片、统一圆角阴影和泛用渐变。
- 在强烈变化之后给稳定阅读状态。让读者看得到变化，也有时间读完。
- 使用 `clamp()` 与内部网格控制字体和留白；可调大字，不把整页 `transform: scale()`。
- 仅使用字体实际存在的轴。附带 Latin 字体：`wght 100–1000`、`wdth 25–151`、`opsz 8–144`；中文字体：`wght 100–900`。中文不应被当作有 `wdth` 轴。
- 变宽会改变布局时，用有边界的展示区或预估最宽状态；不要把其他内容推到视口外。不要用横向拉伸来模拟正文可变字体。
- 标题每字动画可以有独立装饰副本；真实语义文本保持完整可读。不要拆开阿拉伯文字连接、组合字符或 emoji 序列；使用 `Intl.Segmenter`。
- 中文标题用语义短语换行；正文不要依赖固定 `white-space: nowrap`。允许装饰字形裁切，禁止重要正文或按钮被裁切。

## 空间

填满页面的感受来自字号、模块比例、视觉重心和网格延展。不要把“充分使用空间”解释成把所有空隙填上；也不要通过整页缩小留下无目的的大块空白。竖屏与横屏分别编排，在低高度屏幕上先压缩边距、切换列数、移出详情，再考虑自然滚动。
