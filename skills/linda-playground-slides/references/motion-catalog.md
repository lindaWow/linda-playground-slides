# 艺术动效与组件目录

## 使用方式

从内容关系选效果。为每个效果指定：**触发 → 变化 → 可读停留 → 离开 → 触控替代 → 减少动态效果**。先做完整稳定状态，再加入运动。不要把所有效果同时运行。

来源记号：`E` EXAT 机制；`C` Codrops Demo 1 补充；`P` 本项目经验扩展。`内置` 表示 starter 有可运行的基础实现；`配方` 表示需要按内容实现，不应宣称已有完整组件。原站机制的内置版本均为独立、简化实现。

## 关键实现配方

### 距离字阵

为一个短字符/词或装饰副本建立有限网格；用一个指针位置和一个 rAF 更新。距离归一化 `d = clamp(distance / radius, 0, 1)`；字重 `w = minWeight + (1-d)^2 * range`。通过离散色阶索引选色，避免随机颜色和持续闪烁。缓存字格位置，resize 后更新；pointerleave 回到均匀字阵。不要为每个字建立事件监听和常驻动画循环。

### 速度波

在 scroll 事件记录位移和时间，用指数平滑速度限制峰值。短标题每字偏移可取 `sin(index * phase + progress) * amplitude * speed`；速度归零时偏移衰减到零。正文与操作区不参与。内置版本只做小角度速度倾斜；要逐字波形时另行实现，避免造成布局抖动。

### 单轴字体实验

先确认实际轴范围，再为每次操作选择一个主轴。给容器留足最大宽度，另保留最小可读字重。中文展示用 `wght`，英文可用 `wdth`；让选择的轴解释“变宽”“变重”等概念。完整设计空间控制器可以独立提供多个滑杆，避免所有轴自动乱变。

### 3D 标签圆柱

给 N 个装饰标签分配 `rotateX(i * 360/N) translateZ(radius)`；由场景滚动进度改变父层角度。半径随容器宽高重算。设置 perspective 和背面隐藏，避免倒字成为唯一标签。关键标签另以真实列表保留，尤其在触控和减少运动模式。不要让 auto-spin 导致读者追着标签读。

### 流程图与细节页

把总览节点做成可聚焦的链接。hover/focus 只预览节点，click 才导航。用节点几何位置计算 SVG 路径，ResizeObserver 后重算；脉冲可以沿当前节点的出边移动。提供有明确用途的返回总览与上一/下一步骤，且保留原阅读位置。移动端改为纵向布局，次级 pipeline 作为辅助，不夺取主体。

### 确定性粒子聚合

从目标图或文字生成固定终点，使用带固定种子的起点和 easing 进行一次聚合。保留正确可读图形作为最终稳定层。二维码须使用用户原图或已验证解码内容生成的精确矩阵；不得由图片模型重绘。避免过亮码点、侵入静区、改变定位点及不停游移；扫描失败时终态回到可靠原图或高对比渲染。手机与 reduced-motion 直接显示稳定终态，并保留可选重播。

## 选择约束

- 对相邻场景变换机制：大字揭示 → 可操作组件 → 安静比较 → 空间转场，可以比四屏同样淡入更有节奏。
- 对同一场景保持一致：不要同时叠加跑马灯、粒子、强透视、随机抖动和反复字重呼吸。
- 根据内容选择 4–8 个主机制就能支撑长叙事；这是设计提示，不能把数量当验收目标。
- 先为每个机制定义“什么时候停止”。装饰无限循环要可暂停；动态造成阅读困难时减弱或删除。
