# 内容编排

## 建立内容映射

在工作文件中列出：`原文要点 → 场景 ID → 主画面 / 详情 ID / 合并位置`。先完成映射，再精简文案。检查列表、资源名、限制条件、数字和专名逐项可追溯；缺少地址的资源先核实官方网址，未核实则保留名称并明确标记待补，不猜链接。

使用三层信息结构：

| 层级 | 放什么 | 推荐呈现 |
| --- | --- | --- |
| 立即看见 | 主题、结论、数字、金句 | 大标题、独立数字、短句、文字构图 |
| 扫读理解 | 分类、对比、流程、简短例子 | 对齐网格、双栏、步骤节点、表格 |
| 主动深入 | 方法细节、步骤、清单、边界情况、参考资源 | 明确命名的抽屉、dialog、折叠区、资源面板 |

详情入口要具体：用“7 个起点问题”“上线检查 · 8 项”“参考工具与网址”，避免整页只有不知内容的“更多”。主画面必须独立成立。演讲者没时间点击时，观众仍能理解论点。

## 从语义决定页面

- 为新的核心判断或叙事转折建立场景，避免机械地把每个小标题切成一页。
- 把需要横向比较的同级内容放在一起；用渐进揭示减少首次进入的信息压力，最后保留共同可见的对齐状态。
- 把长流程分为总览和子章节。主总览使用大字号可点击节点；将轻量步骤导航放在子章节旁边或底部。返回总览时记住阅读位置。
- 对技术地图保留真正的表格关系。手机可转成含相同字段名称的卡片；如果必须横向滚动，给出明确提示并保留行标题。
- 压缩解释性段落为关键词、步骤或金句；在详情中保留具有独立价值的实践材料。
- 对自主阅读版本增加必要的上下文；对演讲版本减少主屏解释。不要把用户原文无差别塞进弹窗。

## 选择场景结构

| 内容关系 | 优先结构 | 可加入的表现 |
| --- | --- | --- |
| 一个强判断 | 标题占主体，小标签提供上下文 | 字重/字宽变化、遮罩揭示 |
| 身份与经历 | 线性起点，随后扩散的标签 | 3D 文字环、字阵、重组 |
| 从无到有 | 大数字、变化路径、实际样例 | 计数、字符聚合、界面生成 |
| 同级分类 | 同屏网格 | 错峰出现、hover 翻面、聚焦展开 |
| 两种方案 | 对照双栏 | 同步控制或状态切换 |
| 可执行流程 | 主流程图 + 子页 + 次级导航 | 连线脉冲、节点预览、焦点跟随 |
| 操作技巧 | 操作区 + 结果区 + 点击深读 | 对话框、浏览器框、控制面板 |
| 技术资料 | 信息表格或结构化资源列表 | 行高亮、详情展开 |
| 总结与问题 | 安静的大标题 | 文字收束、减速、停留 |

## 文案规则

- 一个主标题只承担一个信息任务；中文按语义短语换行。
- 不因为大字号删掉限定词、数字单位、否定词或因果关系。
- 不把英文全部大写当成唯一的视觉办法；处理中文与英文的字号、重量和基线关系。
- 标题、标签、说明、资源四层应有明确差别。小字用于辅助信息，不能承载唯一可用的操作说明。
- 保留用户有意设置的金句，不把全部句子改成宣传口号。
- 参考链接用准确名称，允许新标签页打开并设置 `rel="noopener noreferrer"`；不要自动打开外部网页。

## 迭代

在副本中完成用户要求的版本分支，记录这轮允许改变的范围。只调整某一章节时，不重排其他章节；只改手机版时，为桌面保留对照截图。新增信息后重新检查最密集页面及中文字体子集。
