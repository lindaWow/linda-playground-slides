# 布局、导航、性能与验收

## 按视口重排

- 使用内容流、CSS Grid、Flex、`minmax(0, 1fr)`、`min-width: 0` 和流式字号。低高度与窄宽度是两个独立条件。
- 演示型主场景可使用 `min-height: 100svh`，在内容确实放得下时才设置固定高度。手机安全区用 `env(safe-area-inset-*)`；需要跟随工具栏变化时再考虑 `dvh`。
- 优先顺序：重排列数 → 调整模块比例与间距 → 调整标题换行和字号 → 把细节移入详情 → 对长内容允许滚动。
- 不设定 1920×1080 画布再整体缩小；不要同时强制一屏、超大字、全部细节和零滚动。
- 允许用户浏览器缩放及捏合缩放。不要设置 `user-scalable=no` 或 `maximum-scale=1`。
- 字体加载完成后检查布局。使用 `overflow-wrap` 处理网址，给 grid/flex 子元素 `min-width: 0`，让图片与 SVG `max-width: 100%`。

## 统一吸附机制

问题模式：一部分章节使用原生场景锚点，另一部分使用很长的 sticky/pin 容器，却没有最终阅读锚点。这会导致后者只能匀速滑过、无法停在完整页面。

解决顺序：

1. 明确唯一主滚动容器。不要同时让根页面、外层容器和章节轮流劫持滚轮。
2. 为每个可独立阅读的场景建立一致的锚点和 `scroll-snap-align: start`。
3. 用 `scroll-margin` 或 `scroll-padding` 补偿固定导航高度。
4. 默认用 `proximity`。只有每一屏都能完整显示、长内容可达且设备适合时再用 `mandatory`。
5. 内部动效可使用滚动进度；最终阅读状态必须有足够区间。对长 pinned 场景，明确其进入、停留、退出边界。
6. 不在详情窗、输入框、表格横滚区、触摸拖动区或正在选择文字时强行切页。
7. 目录点击、键盘导航、返回总览和滚动吸附应到达同一个阅读位置。

附带 starter 使用原生 proximity 和可见场景标记；需要强 pin 或整屏翻页时按上述原则增加。不要把“使用了 ScrollTrigger / Lenis”当成已经具备完整吸附。

## 手机替代

| 桌面效果 | 手机处理 |
| --- | --- |
| 光标距离字阵 | 减少字数，点击切换或稳定构图 |
| hover 详情 | 可见的点击按钮 |
| 3D 标签环 | 更浅景深、较小转速；保留可读的标签列表 |
| 磁吸/倾斜 | 关闭光标跟随，保留按压反馈 |
| 多栏内容 | 重新排成一至两列，标题按语义换行 |
| 四列表格 | 同字段卡片或明确可操作的横向滚动 |
| 横向流程 | 可折行或纵向，保证每个节点足够大 |
| 持续粒子 | 减少数量，收束后停止，低性能时静态落版 |
| 固定主场景高度 | 内容不足以放下时改为自然高度 |

触控目标建议至少 44×44 CSS px。详情窗在窄屏使用接近全宽的面板，允许内部滚动；Esc、关闭按钮、焦点恢复都应工作。

## 动画生命周期

- 只在可见区域保留 rAF。页面隐藏时暂停；离开场景时停止计时器、音频和重绘。
- 鼠标事件只写入目标值；在一个 rAF 中更新样式。不要为每个字创建各自的永久循环。
- 读取布局集中处理，使用 ResizeObserver 更新缓存；避免逐帧读写交替触发布局。
- 对 `prefers-reduced-motion: reduce` 展示最终可读状态，保留按钮交互与信息，取消无限循环、抖动和强透视运动。
- 字体轴动画可能触发重排或重绘，限制字符数量和活动区域。不要给整篇文章持续变形。
- 内容揭示不能依赖 JS 一定成功；脚本失败时也应显示正文或有可读降级。

## 验收矩阵

至少检查：1440×900、1280×720、390×844、320×568、844×390；根据用户设备补充尺寸。检查首屏、最密集页面、流程总览、最长详情、结尾和所有新增页。

- 无横向意外溢出，无关键元素被裁切，无整体缩小导致的大空白。
- 主内容在桌面充分展开；手机不靠过小字或不可触达的 hover 阅读。
- 进入和离开每个场景后均能稳定停留；重点检查实现机制不同的章节。
- 默认和交互状态的相邻模块颜色清晰区分，文字和焦点可见。
- 流程节点、返回、弹窗关闭、资源链接、控制器都可用；Tab 顺序合理。
- 减少动态效果和触控设备下信息完整；200% 缩放时核心阅读和操作仍可达。
- 最终导出的单文件能断网打开，实际字体字形完整，Console 无错误。

单纯测量 `scrollWidth` 不足以证明视觉正确。结合截图、完整滚动和真实操作；若环境不支持实测，具体记录未完成的部分。
